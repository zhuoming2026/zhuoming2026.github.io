v0.1.5即将发布发布日期待定

即将发布 · 创世原生角色卡、Agent 写手、章节润色与写手改进、并行与分支会话、历史整理及模型配置。本版仍在验收，当前可下载版本为 0.1.4。

创世与原生角色卡

  • 创世改为围绕完整原生角色卡编辑：角色字段、世界书、开场白、互动选项和酒馆扩展集中在同一份草稿中。
  • 可以从已有角色卡创建独立草稿，完成后覆盖所选角色卡或另存为新卡；角色卡列表按导入时间排列，新导入内容更容易找到。
  • 创世支持编写 MVU 变量定义、初始值和状态栏内容，并编译、预览开场；酒馆扩展可逐项新增、修改或删除。
  • 创世小精灵更新角色卡创作知识，可按需读取资源库中的创世 Skill；字段提示、分栏说明和待完成项帮助检查草稿。

单步写手与三槽 Agent 写手

  • 写手分为单步写手和三槽 Agent 写手。三槽分别编辑身份、演绎规则和文风指导；旧格式保留数据，但不再用于写作。
  • Agent 写作按阶段处理演绎规则、文风和正文工作稿，使用当前故事资料与前文，完成检查后才交付正式章节。
  • Agent 可以在本轮工作稿上读取、修改和检查；自编辑次数受到限制，未完成的中间稿不会成为正式正文。
  • 在运行记录中查看写作阶段、资料来源、工具活动和模型用量；开启开发者模式后可查看模型实际返回的思考内容。
  • 写手列表标识与说明统一；选择、新建或复制写手后，地址栏定位到该写手，刷新及前进、后退可恢复选择。写手小精灵仅支持单步写手。

章节润色与写手改进

  • 章节支持原文、渲染和润色稿三种阅读方式。润色稿独立保存，不替换原文，也不参与后续剧情、状态与历史总结。
  • 润色时可以单独选择写手并填写本次要求；后台处理完成后，从任务中心打开结果。
  • 可以结合整章或选中的正文片段提出写手改进要求，也可以在润色时一并生成写手改进提案。
  • 写手改进只有经确认才会写回规则；三槽 Agent 写手的改进提案只涉及演绎和文风，保留身份槽。

并行会话与章节分支

  • 故事顶栏可下拉切换已有会话，各会话分别保留输入、消息和写作进度。
  • 切换会话或浏览器连接断开后，已受理的写作继续在后台进行；取消一局不会替另一局取消。
  • 可从指定章节创建独立分支，复制到该章为止的原文与会话状态，从下一章继续另一条故事线；原会话保留。

长篇历史与写作参考

  • 历史面板可补齐章节总结，并压缩已有总结，便于整理长篇故事。
  • 按会话设置最近原文章节数，并手动选择需要带入写作参考的历史章节。
  • 历史章节支持范文星标、单章总结折叠和原文章号标注，更容易区分摘要与原文来源。

Tavern、MVU 与状态栏兼容

  • 补充角色卡 EJS 模板、iframe 和卡内脚本运行支持，完善 ESM Schema 脚本与 Zod 注册识别。
  • 补齐部分酒馆聊天 API 与事件参数处理，减少卡内脚本因宿主差异失败的情况；具体卡片仍需实际验证。
  • 支持状态栏把文字填入故事输入框，填入后由用户检查并发送。
  • 创世编辑保留互动选项；MVU 更新明确使用 stat_data 根路径，移除旧的手动文本识别入口。

模型连接与目录

  • 完善保存前兼容性测试，分别检查基础生成、结构化输出和单轮 Agent；修改连接地址、密钥、模型或推理等级后重新测试。
  • 推理等级按模型目录声明提供，可随连接保存；对部分网关拒绝的默认推理强度进行实测校正。
  • 模型目录随版本提供，用户可手动更新已收录模型的上下文、输出上限及推理等级信息。
  • 补齐 OpenCode Go 所需的会话请求信息，改善相关网关的连接与生成兼容性。

界面与日常使用

  • 新增「关于 Loresis」与手动检查更新，可查看当前版本并打开官网或 GitHub。
  • 外观设置可控制 Bloub 是否显示；创世、小精灵和写手助手输入框支持拖动调整高度。
  • 创世字段、角色卡保存、列表顺序和编辑说明得到整理，减少查找入口与保存结果时的困惑。

修复与发布收尾

  • 修复部分 Tavern 展示内容被误判为机器协议，以及写作失败重试时重复带入用户输入的问题。
  • 引号归一化不再改写机器协议块中的 JSON；补回 Agent 写作参考中的蓝灯和在场角色核心资料。
  • 上游明确返回内容过滤时及时报错，避免没有有效正文却继续空转；完善 Agent 完成检查和运行摘要。
  • 同步小精灵对当前功能的说明，统一 0.1.5 版本，并补齐模型目录附件的发布链路。

当前限制

  • 当前创世界面没有提供草稿包导入导出入口；草稿可在本机复制，保存为角色卡与导出草稿包是不同操作。
v0.1.42026-09-18

让角色卡真正跑起来，也让长篇故事写得更久。

这次更新主要围绕三个方向：更完整的酒馆角色卡体验、更自由的状态栏，以及更适合长篇故事的写作方式。

酒馆角色卡，导入后就能玩

Loresis 现在可以更完整地使用角色卡原本携带的状态栏、数值规则、MVU 和正则。

你可以直接查看、编辑和预览这些内容；故事进行途中修改，也会从下一轮开始生效，不需要重新开局。

世界书也得到进一步支持，包括酒馆世界书导入和全局世界书。

自己做一个状态栏

不依赖角色卡，你也可以为自己的故事创建状态栏。

生命值、好感度、身份、装备、开关状态……想记录什么，就创建什么。

状态栏支持单角色和多人列表，也可以直接描述想要的效果，让 AI 帮你生成样式。

制作完成后还能保存到资源仓，在其他故事里继续使用。

长篇故事可以一直写下去

随着章节越来越多，Loresis 会自动整理过去的故事。

近期章节保留详细信息，更早的内容逐渐压缩为历史总结，在尽量保持故事记忆的同时，避免上下文不断膨胀。

正文和摘要始终保留，你也可以随时编辑它们。

长篇会话的加载方式也重新设计，不再一次渲染整个故事。

故事进行中，也可以继续修改

角色卡、世界书、状态记录和状态栏不再只是「开局配置」。

故事已经开始以后，你仍然可以修改规则、增加角色、调整数值，下一轮直接使用新的内容。

Loresis 不替你锁死故事——这是你的游戏，你可以随时改变它。

更简单的模型与界面

模型配置现在收敛为「连接」和「绑定」。

保存前会自动测试基础回复、结构化输出和 Agent 能力，尽量在真正开始故事之前发现兼容问题。

主题系统、三栏工作区、角色卡详情、创世首页和日志诊断也进行了重新整理。

这次更新的重点不是增加更多开关。

而是让角色卡、世界书、状态和故事本身，都变成可以在游玩过程中持续修改、持续生效的东西。

历史版本

v0.1.32026-08-23

写作过程更可观察、更可控，酒馆兼容闭环，三个创作 Agent 登场。

写作连续性与状态

  • 章节双层总结：每章自动生成五要素总结，最近 5 章用扩展摘要、更早章节用短摘要进入写作参考。
  • 时间与退场自动维护：时间倒退会被拒绝并记录；退场角色自动登记。
  • 在场角色的核心资料会稳定进入写作参考，不会被上下文挤掉；卡片数值状态也会一并带入。
  • 世界书词条设置条：蓝灯、注入位置、启用与关键词平铺展示，直接编辑即时保存。
  • 「@」提及扩展到世界书词条与关键词。
  • 消息里的状态栏可以折叠，输入区新增一键开关；新增「显示提示词」查看本轮完整提示词。

创作 Agent

  • 写手 Agent：在写手区对话式调教写手——只读检索资源仓、提案式整体替换字段、应用前弹框预览。
  • 小精灵多会话：自动命名、切换、删除，独立授权看板。
  • 创世 Agent 增强：解除轮数上限、对话历史按草稿隔离；Markdown 设计文档一键导入。
  • Bloub 桌宠：会话、写手、创世区常驻，气泡跟随写作事件，可拖拽、可切换形态。

模型与兼容

  • 按模型自动适配接口协议，修复部分网关「能聊天但工具调用失败」的问题。
  • 内置供应商新增 OpenCode Zen；自定义网关只需填地址即可拉取模型列表。

日志与支持

  • 软件日志分级，并新增模型用量账本（不记录提示词与回复内容）。
  • 写作回合追踪（开发者模式）：查看提示词分块、模型调用与回合诊断包导出。
  • 日志保留策略与空间回收。
  • 「故障与支持」：问题卡片直达处理入口，新增一键删除与 GitHub Issue 入口。

界面

  • 全站动效体系与动效总开关。
  • 角色卡库游戏库式首页：精选大卡、最近剧情摘要、毛玻璃、软弹簧入场。
  • 桌面原生页面缩放；右侧检查栏默认折叠并按会话记忆。
  • 故事与创世封面上传、裁剪、替换；实验性全屏背景图；教程升级为线上手册。

修复

  • 修复状态栏显示：桌面端背景色、高度自适应不再出现常驻滚动条、空状态栏不再生成空白面板。
  • 修复封面编辑弹窗首次打开卡顿、取景偏移与字体加载引发的布局漂移。
  • 修复模型连接测试与模型列表拉取的多处体验问题。
  • 修复按钮文字颜色被自定义字号覆盖、点击后焦点高亮残留。
v0.1.22026-08-10

本地 AI RPG / 角色扮演与连续故事创作：模型能力体系、故事解析重构与 Docker 发布通道。

新增

  • 模型能力体系：内置模型索引，输出上限自动跟随所选模型，长文写作不再被截断。
  • 故事解析重构：候选提取与全局归并、MVU 定义独立、统一的提示词结构，解析完成后既有会话的写作自动增强。
  • 没有蓝图也能开局：角色卡详情实时显示解析进度，也可以跳过解析直接生成默认蓝图。
  • 写手 v2：写手与资料双页签、卡片式编辑、草稿机制废除；写手决定自检区。
  • 全局视觉变量统一：字号、状态色、圆角、阴影与动效。
  • 全局通知与统一弹框。
  • 三层字体系统：系统字体、内置文楷与思源宋体、用户字体上传，行距可调。
  • 章节阅读优化：消息风格统一、章节操作条、装饰性分隔线。
  • 输入框工具栏重构：写作方式合并弹框、「自动」继续按钮、发送快捷键提示。
  • macOS 红绿灯避让与侧边栏动态展开宽度；资源仓支持多选批量删除。
  • Docker 发布通道：支持 NAS 与 Linux 服务器部署，浏览器访问，数据保存在本地卷。

修复

  • 创建会话时默认写手优先使用当前选中的写手；修复写手卡片删除与排序失效。
  • 统一章节折叠块的字体与交互。
  • 修复故事页收起右侧栏后展开按钮点不到。
  • 历史消息不再重放流式打字机动画。
  • 角色卡数据异常时创建会话会给出提示并回滚失败的目录。
  • 删除写手卡片后不再复活；自定义网关聊天路径关闭思考。

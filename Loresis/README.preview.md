## 💬 常见问题 · 轻问快答

<details>
<summary><b>Q: 我是纯小白，能用吗？</b></summary>

能！手册就是为小白写的。Ch1 会手把手教你从零开始，不用懂代码，跟着截图点就行。猫猫都会，你也会。🐾

</details>

<details>
<summary><b>Q: 手册和 README 有什么区别？</b></summary>

README 是地图，手册是向导。README 告诉你「这里有什么」，手册带你「一步一步做出来」。想快速了解看 README，想真正上手一定要点进手册。→ [去手册](https://zhuoming2026.github.io/Loresis/)

</details>

<details>
<summary><b>Q: 需要科学上网吗？</b></summary>

手册本身是 GitHub Pages，国内可直连。模型配置部分取决于你选的模型服务商，手册里有说明。

</details>

<details>
<summary><b>Q: 图片加载不出来怎么办？</b></summary>

本 README 所有图片用的都是 `https://zhuoming2026.github.io/Loresis/...` 绝对路径，GitHub 预览可直接加载。如果本地预览不到，请检查是否离线，或直接线上阅读手册。

</details>

## 🖼️ README 怎么放图片？

> 给想自己改 README 的小伙伴，3 种常用方法，GitHub 都能渲染 👇

### 方法 1 · 相对路径（仓库内图片）

适合放在仓库里的图，提交后 GitHub 自动解析。

```markdown
![meditating cat](./images/meditating_cat_illustration.png)
![demo](./images/demo.png)
```

### 方法 2 · 绝对 URL（推荐用于 GitHub Pages 预览）

本 README 全部用这种，保证在 GitHub 列表页也能直接加载，不受分支/路径影响。

```markdown
![Hero](https://zhuoming2026.github.io/Loresis/_astro/hero.GRxRDYw4.png)
![Ch1](https://zhuoming2026.github.io/Loresis/_astro/1-1.BqWzvf9p.png)
![黑色原型](https://zhuoming2026.github.io/Loresis/_astro/%E9%BB%91%E8%89%B2%E5%8E%9F%E5%9E%8B.CmG_S5fn.png)
```

> 中文文件名记得 **URL 编码**，比如 `黑色原型.CmG_S5fn.png` → `%E9%BB%91%E8%89%B2%E5%8E%9F%E5%9E%8B.CmG_S5fn.png`

### 方法 3 · HTML 控制大小 / 圆角 / 阴影（最灵活）

想让图片圆角、控宽度、加阴影，就用 HTML。在 GitHub Markdown 里是允许的。

```html
<!-- 居中 + 圆角阴影大图 -->
<p align="center">
  <img
    src="https://zhuoming2026.github.io/Loresis/_astro/hero.GRxRDYw4.png"
    width="860"
    style="border-radius: 32px; box-shadow: 0 24px 64px rgba(232,165,152,0.28); border: 1px solid #F0E6E0;"
    alt="Hero"
  />
</p>

<!-- 横向多图，控制每张宽度 -->
<p align="center">
  <img src="https://zhuoming2026.github.io/Loresis/_astro/1-1.BqWzvf9p.png" width="200" style="border-radius:16px;" />
  <img src="https://zhuoming2026.github.io/Loresis/_astro/2-1.BlBYrj1J.png" width="200" style="border-radius:16px;" />
  <img src="https://zhuoming2026.github.io/Loresis/_astro/3-1.DwOVDJyr.png" width="200" style="border-radius:16px;" />
</p>
```

**小技巧：**
- `width="200"` 控制大小，比 Markdown 的 `![alt](url)` 更可控
- `style="border-radius: 16px; box-shadow: ..."` 加圆角和阴影，和手册风格统一（`#F9F6F1` 米白 + `#E8A598` 珊瑚粉）
- 外层包 `<a href="https://zhuoming2026.github.io/Loresis/">` 就能让图片可点击跳转
- 只用 `div / table / p / img / a` + 行内 `style`，不要引入外部 CSS，GitHub 才会保留样式
